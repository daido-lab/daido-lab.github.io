Gmail MCP

本アプリケーションは、開発者本人が自身の Gmail アカウントを MCP (Model Context Protocol) 経由で操作するための個人利用ツールです。 第三者への提供は行っていません。

プライバシーポリシー

  • 本アプリは開発者本人のみが使用します。
  • Google アカウントから取得したデータ（メール等）は、本人の端末上でのみ処理されます。
  • 取得したデータを第三者に提供・販売・共有することはありません。
  • 取得したデータを外部サーバーに保存することはありません。
